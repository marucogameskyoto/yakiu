# やきうさしこみ

メイアたちの雑談に、プレイヤーがこっそり「やきう」を差し込むスマホ向けミニゲームです。

## 遊び方

1. `index.html` をブラウザで開きます。
2. `開始` を押します。
3. 会話の流れを見ながら `やきう` ボタンを押します。
4. 気づかれなければ +1 点、バレると -1 点です。
5. 3 回バレるとゲームオーバーです。
6. 制限時間は 1 分です。

## GitHub Pages

このフォルダの中身をそのままGitHubリポジトリにアップロードすれば動きます。

GitHub Pagesで公開する場合:

1. リポジトリにこのフォルダの中身をアップロードします。
2. `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選びます。
4. `main` ブランチの `/root` を指定します。
